The editable source artwork is `src/assets/logo.svg`. It defines both rounded diamonds, their positions and corner radii, the transparent cutout, and the violet fill `#5f3afc`. The larger violet insert extends into the main diamond as a deeper cutout. The mask's `stroke-width="18"` creates a 9px gap around the insert in the 128px viewBox. Edit the SVG and run `pnpm icons:generate` to regenerate all 12 PNGs. Generated PNGs should not be edited directly.

`light/` contains the charcoal-and-violet mark for light backgrounds. `dark/` sets the SVG's `data-body` shape to light ink before rasterizing; the violet shape and fill are identical in both themes. Every size is rendered from SVG. The options and popup select these assets using the page's `.dark` theme class. Both pages currently use a dark theme. The favicons and root README select the same variants using `prefers-color-scheme`.

The browser action follows Chrome's `prefers-color-scheme` preference, including while the popup and options page are closed. An offscreen document observes the media query and reports changes to the service worker, which updates the icon. It also checks the value once per second because Chromium defers media-query change events in hidden documents; browser timer throttling can delay these checks. It confirms the initial theme through a successful worker acknowledgement, then sends no messages for unchanged themes. Unsuccessful updates are retried, including a failed initial icon update. The `offscreen` permission is used only for this theme observer. Chrome's [Offscreen API](https://developer.chrome.com/docs/extensions/reference/api/offscreen) supports the `MATCH_MEDIA` reason and keeps the observer separate from the user interface.

The PNGs directly in this directory use a filled light mark with a thin charcoal inner edge, keeping the silhouette visible on both light and dark backgrounds. They are the manifest fallback before theme synchronization or if it fails, and are also used by Chrome's extension management page. Chrome's [manifest icons](https://developer.chrome.com/docs/extensions/reference/manifest/icons) are separate from the toolbar's runtime icon, so the management card uses this static artwork. All variants have transparent backgrounds. Theme-specific icons use no keyline. Custom browser colors can differ from the reported light/dark preference.

To regenerate all variants in four sizes from the project root, run `pnpm icons:generate`. The generator uses the project's Playwright dependency and requires its Chromium browser to be installed with `pnpm exec playwright install chromium`.
