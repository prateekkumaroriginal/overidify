# Button font

`suisse-intl-medium.woff2` is the 500-weight Suisse Intl font used by the reference buttons on [Clerk Docs](https://clerk.com/docs/nextjs/getting-started/quickstart).

Source declarations: [Clerk font stylesheet](https://clerk.com/_next/static/immutable/chunks/24cyz9un29qmh.css).

Source font: [Suisse Intl Medium](https://clerk.com/_next/static/immutable/media/SuisseIntl_Medium-s.p.3034-r-4niicv.woff2).
